# LINK DRAWER

A retro-inspired link organizer designed around the concept of traditional filing cabinets and suspended folders.

---

## How to Run

1. Download or clone this repository to your computer.
2. Navigate to the following folder path inside the project:
   `bin/Release/`
3. Double-click the `LinkDrawerApp.exe` file (or your project's named `.exe`) to launch the application.

*Note: Visual Studio or any other code editor is not required to run the application directly from the Release folder.*
